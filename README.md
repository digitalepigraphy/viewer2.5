# viewer2.5

Legacy heightmap viewer of the Digital Epigraphy Toolbox.

To use it:
1. Create a collection as a new GitHub project and enable the GitHub pages feature.
2. For each inscription create a separate folder with its accession number (e.g. MOM_EST_701007_300002)
3. Place inside the folder the Heightmap.png and Info.xml
4. Optionally add any of the following images: ImageBottom.png, ImageTop.png, ImageLeft.png, ImageRight.png, Normalmap.png

Consult the following example: https://github.com/digitalepigraphy/Delphi/tree/main/MOM_EST_701007_300002

Each inscription can be viewed as: `https://digitalepigraphy.github.io/viewer2.5/view.html?heightmap=` followed by  `[COLLECTION NAME]/[ACCESSION NUMBER]` 

Live example:
https://digitalepigraphy.github.io/viewer2.5/view.html?heightmap=Delphi/MOM_EST_701007_300002
